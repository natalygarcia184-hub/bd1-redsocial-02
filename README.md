# bd1-redsocial-02
Este repositorio tendra las tareas sobre esta materia Base de Datos

Nombre del proyecto : Red social estudiantil pascualina

Integrantes del equipo:_ Nataly Garcia Crespo, Leancy Garcia Restrepo

Breve descripción del caso :  El proyecto tiene como objetivo diseñar un modelo entidad-relación para una Red Social Estudiantil Pascualina. Esta plataforma se creó para mejorar la comunicación, la interacción y el trabajo en equipo entre los estudiantes. Los usuarios podrán crear sus perfiles, subir contenido académico y social, comentar, reaccionar a las publicaciones, unirse a grupos de estudio y organizar eventos dentro de la comunidad educativa.

Para llevar a cabo la propuesta, se identificaron las entidades, los atributos y las relaciones necesarias. Se definieron las llaves primarias, las cardinalidades y la estructura de la base de datos. Este modelo será la base para el desarrollo del modelo lógico y la implementación final de la base de datos.
